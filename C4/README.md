# C4

Esta pasta concentra os modelos arquiteturais da plataforma.

## Diagramas planejados

- contexto atual e alvo;
- containers da plataforma;
- componentes do workflow orchestrator;
- componentes de document intelligence;
- implantação local, homologação e produção;
- trust boundaries e fluxos de dados sensíveis.

Os diagramas devem distinguir claramente **implementado**, **baseline executável** e **arquitetura-alvo**.
