# Governança

A governança deve começar pelo outcome e pelo risco, não pelo modelo ou framework de agentes.

## Gates iniciais

- owner de negócio e técnico definidos;
- baseline e target documentados;
- classificação de dados aprovada;
- threat model e privacy assessment concluídos;
- contratos e policies versionados;
- dataset de avaliação publicado;
- segregação entre recomendação, aprovação e execução;
- rollback e runbook disponíveis;
- evidências vinculadas à versão promovida.

## Decisões possíveis

Cada revisão de valor deve resultar em uma decisão explícita: escalar, ajustar, pausar ou descontinuar.
