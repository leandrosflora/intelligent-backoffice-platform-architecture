# Serviços planejados

| Serviço | Responsabilidade |
|---|---|
| Case Intake Service | receber e normalizar solicitações e documentos |
| Workflow Orchestrator | manter estado, timers, retries e compensações |
| Document Intelligence Service | classificar, extrair e validar documentos |
| Investigation Agent Runtime | reunir evidências e executar consultas autorizadas |
| Decision Support Agent Runtime | produzir recomendação explicável |
| Backoffice Tool Service | expor ferramentas governadas por MCP ou API |
| Human Approval Service | registrar aprovação, rejeição e justificativa |
| Execution Service | executar ações em sistemas corporativos |
| Evidence Service | armazenar referências e versões das evidências |
| Audit Service | manter trilha imutável da jornada |

Os limites poderão ser agrupados no MVP e separados conforme escala, risco e ownership.
